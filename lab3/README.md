# Лабораторна робота №3 — Робота з CSS

Резюме Остапа Левинця у двох реалізаціях. Використано матеріали лабораторної №2.

## Частина 1: HTML + CSS

Відкрийте `index.html` у браузері. Основні стилі містяться у `styles.css`.

Виконані вимоги:
- Зовнішній CSS через `<link>`, внутрішній через `<style>` та один inline-стиль.
- Селектори тегів, класів, ID, атрибутів; псевдокласи `:hover` і `:focus-visible`.
- `margin`, `padding`, `border`, `box-sizing: border-box`.
- CSS Grid для основних блоків і Flexbox для навігації та підвалу.
- Медіазапит до 640 px: одна колонка та вертикальна навігація.

## Частина 2: React + Tailwind CSS 4

У терміналі з кореневої папки:

```sh
cd lab_3_react
npm install
npm run dev
```

Відкрийте адресу, яку надрукує Vite (зазвичай `http://localhost:5173`).

Tailwind підключено плагіном `@tailwindcss/vite` у `vite.config.js`.
`src/index.css` містить лише `@import "tailwindcss";` і підключається у `src/main.jsx`.
Усі компоненти оформлено утилітарними класами Tailwind, без власних CSS-правил та inline-стилів.
Адаптивність реалізовано через `sm:`, стани посилань — через `hover:` і `focus-visible:`.

Перевірка збірки:

```sh
npm run build
```

Для демонстрації порівняйте вигляд на широкому екрані та за ширини 390 px.
